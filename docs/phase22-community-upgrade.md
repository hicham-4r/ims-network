# Phase 22 community upgrade
- Preview only: keep the verified TCP adapter (RESP2, TLS certificate checks) unchanged. Enable `IMS_PHASE22_CHAT_ACTIVITY=true` for opt-in activity. No permanent sockets outside messaging. Activity is scoped to the selected conversation via an HMAC token; never carries message text or raw account IDs. Redis entries expire for display after 10/45 seconds, remain in the existing bounded stream until trimmed. No idle heartbeat. “Recently active” is not global online presence. Each active sender can publish at most 8 notices/minute; each requires authenticated membership, Redis rate limit, one stream append, and existing recipient authorization. Idle cost is unchanged; actual provider usage must be measured.
- Browser delivery marks individual incoming IDs loaded on the current latest history page, not a range. Acknowledgment is best effort, not cryptographic proof of device delivery. Read overrides delivery. Existing history has no fabricated delivery timestamps. One batch up to 30 IDs, only changed records publish a notice.
- Notifications show persistent incoming-message history backed by messages and read cursor; no duplicate per-message notification rows. No push, all-event history or global live badge. Message reports are stored separately and visible to reporter. No private bodies are shown to reviewers.
- Moderator is a separate review-only capability, not ADMIN. Owner password confirmation required to grant/revoke. Current active account and session required for each read/mutation. Suspension blocks access; owner should revoke capability if restoration must not restore it. Reviewers cannot act on their own reports or reports about themselves; escalation goes to admin queue, never suspends automatically. Decisions/role changes are audited. Reports may be deleted by FK cascades if underlying message/reporter is deleted in a future lifecycle workflow. Account deletion remains manual. Export includes own report data paginated with related messages.
- Analytics is opt-in admin aggregate of surviving account registrations by calendar month (not historical growth). No added dashboard queries by default. CSS charts and motion honor reduced motion.
- Schema additive. Source rollback cannot undo schema changes. Verify recovery before migration; keep Development and Production isolated. Test with two synthetic accounts and separate moderator/admin test cases. Do not grant moderator to real users until negative authorization tests pass. No automatic deployment or credential changes.
