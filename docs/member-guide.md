# Member guide

IMS Network is a private alumni community with a public entry page. Visit https://ims-network.vercel.app.

## Join and connect

Register with an email address and strong unique password. No mandatory email-verification link is sent. An administrator reviews membership; pending, rejected and suspended accounts cannot access private member data. Provide accurate alumni information and follow the administrator's independent eligibility checks.

Once approved, complete your professional profile and optionally upload a profile picture, list skills and mentorship availability. Use the directory to find approved members. Private conversations support replies, emoji reactions, sending status and incoming-message history. Sent, Delivered and Read have distinct meanings; delivery is browser acknowledgment, not a guarantee across devices. Typing and recent activity are opt-in and conversation-scoped, not a global online tracker.

## Account security and recovery

Use Account & Security (`/account-privacy`) to change your password with the current password. A successful change signs out all existing sessions and invalidates a saved recovery code. Sign back in and generate a replacement code if eligible. Never share passwords, recovery codes or session information.

If your email was previously verified and recovery delivery is available, use Forgot password. Ordinary unverified email addresses cannot receive trusted reset links. Eligible members can generate and privately store a single-use recovery code at `/account-recovery` and use `/recover-with-code` if needed. The owner has separate recovery restrictions. If you have neither a valid password nor a recovery method, contact the owner through a trusted channel; recovery is not guaranteed.

## Privacy, moderation and installation

Use Account & Security to request a personal data export or eligible deletion request. Deletion requests are reviewed manually; they do not automatically erase an account. Report inappropriate messages through the available reporting workflow. Moderators review report metadata, not private message bodies.

Use the browser's Install app or Add to Home screen action if available. The installed PWA still requires connectivity and normal account authorization. Private account data and conversations are not stored by the service worker for offline access. Use light/dark/system themes and the keyboard command palette as preferred.

For problems, contact the owner privately. Never post raw logs, reset links or personal data in public issues.
